# Incident Handler's Journal

## Overview

A collection of cybersecurity learning activities and reflections completed as part of the Google Cybersecurity Certificate.

This journal documents introductory exercises involving incident documentation, network traffic analysis, and threat investigation.

## Activities Covered

### 1. Ransomware Incident Documentation
Analyzed a simulated ransomware incident affecting a healthcare organization. Used the 5 W's to document the incident, identify the attack's initial access method, and understand its operational impact.

### 2. Wireshark Packet Capture
Explored Wireshark as a graphical network protocol analyzer and learned how packet capture analysis supports security monitoring and investigation.

### 3. Capturing Network Traffic with tcpdump
Practiced using tcpdump through the command line to capture, filter, and analyze network traffic. Developed familiarity with command-line network analysis.

### 4. VirusTotal File Hash Investigation
Investigated a suspicious file hash associated with a malicious email attachment at a simulated financial services company. Explored how VirusTotal can support threat intelligence research and SOC alert investigation.

## Tools and Technologies

- Wireshark
- tcpdump
- VirusTotal
- SHA-256
- Intrusion Detection Systems (IDS)

## Key Learning Outcomes

- Understanding the incident detection and response lifecycle.
- Documenting security incidents using the 5 W's.
- Understanding network protocol analysis tools.
- Capturing and examining network traffic.
- Understanding Indicators of Compromise (IoCs).
- Using file hashes to support threat investigations.
- Developing analytical thinking and troubleshooting skills.
