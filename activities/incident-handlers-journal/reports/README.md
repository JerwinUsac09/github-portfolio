
# Supporting Documentation

This folder contains the completed Incident Handler's Journal from the Google Cybersecurity Certificate.

The journal includes four learning entries covering:

1. Ransomware incident documentation.
2. Introduction to Wireshark packet capture analysis.
3. Network traffic capture using tcpdump.
4. VirusTotal file hash investigation.

It also includes personal reflections on learning network analysis tools and understanding the incident detection and response lifecycle.
