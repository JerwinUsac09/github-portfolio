
# Finding Files with Linux Commands

## Overview
A hands-on Linux command-line activity completed as part of the Google Cybersecurity Certificate training.

## Objective
Navigate the Linux filesystem, locate specific files, inspect user records, and review log information using basic Linux commands.

## Tools
- Kali Linux / Linux terminal
- Bash

## Commands Used

| Command | Purpose |
|---|---|
| `pwd` | Display the current working directory |
| `ls` | List files and directories |
| `cd` | Navigate between directories |
| `cat` | Display the contents of a file |
| `head` | Display the first 10 lines of a file |

## Activity Performed

1. Identified the current working directory using `pwd`.
2. Listed directory contents using `ls`.
3. Navigated to the `reports` directory.
4. Located the `users` subdirectory.
5. Displayed user records from `Q1_added_users.txt` using `cat`.
6. Navigated to the `/home/analyst/logs` directory.
7. Inspected the first 10 lines of `server_logs.txt` using `head`.

## Observations

The user records file contained employee IDs, usernames, and department information.

The server log contained entries related to successful logins, incorrect passwords, incorrect usernames, storage warnings, and password expiration notifications.

## Skills Demonstrated
- Linux filesystem navigation
- Command-line operations
- File inspection
- Basic log review
- Understanding directory structures and absolute paths
