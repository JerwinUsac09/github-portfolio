# Supporting Documentation

This folder contains the original reports from two Linux command-line exercises completed as part of the Google Cybersecurity Certificate.

The reports document:

1. **Linux File Navigation and Log Inspection** – Using Linux commands to navigate directories, locate files, and inspect user records and server logs.
2. **Linux File and Directory Management** – Creating and removing directories, moving and deleting files, and creating and modifying text files.

These reports provide supporting evidence of the command-line tasks performed during the training exercises.
