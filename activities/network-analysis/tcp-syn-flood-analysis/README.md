# TCP SYN Flood Attack Analysis

## Overview

A simulated cybersecurity incident analysis activity completed as part of the Google Cybersecurity Certificate training.

## Objective

Identify and analyze a suspected TCP SYN flood attack affecting a company's web server.

## Topics Covered

- TCP three-way handshake
- SYN flood attacks
- Denial-of-Service (DoS)
- Half-open TCP connections
- IP spoofing
- Network availability

## Skills Demonstrated

- Understanding TCP connection establishment
- Identifying potential DoS attack patterns
- Analyzing network service disruptions
- Recommending network security improvements

## Supporting Documentation

See the `reports` folder for the incident analysis report.

## Disclaimer

This is a simulated cybersecurity training exercise, not an actual professional incident investigation.
