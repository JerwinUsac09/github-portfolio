
# Network Security Hardening Assessment

## Overview
A simulated cybersecurity risk assessment activity completed as part of the Google Cybersecurity Certificate training.

The scenario involved a social media organization that experienced a data breach exposing customer names and addresses.

## Objective
Identify security vulnerabilities within the organization's network and recommend appropriate hardening measures to reduce security risks.

## Identified Vulnerabilities
1. Employees sharing passwords.
2. Database administrator account using a default password.
3. Firewalls lacking inbound and outbound traffic filtering rules.
4. Absence of multi-factor authentication (MFA).

## Recommended Security Measures
- Implement MFA to strengthen authentication.
- Establish and enforce strong password policies.
- Require unique individual user accounts and prohibit credential sharing.
- Replace default database credentials immediately.
- Configure and regularly review inbound and outbound firewall rules.
- Apply account login restrictions to reduce brute-force attempts.

## Security Concepts Demonstrated
- Network security hardening
- Authentication and access control
- Password security
- Firewall filtering
- Risk identification and mitigation
- Security control recommendations

## Skills Demonstrated

- Evaluating security vulnerabilities
- Recommending appropriate security controls
- Explaining the importance of network protection
