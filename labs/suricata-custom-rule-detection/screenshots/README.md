# Suricata Lab Evidence

This folder contains selected terminal screenshots from the Suricata custom rule detection and log analysis activity.

The screenshots document:

1. Custom Suricata rule configuration.
2. Execution of Suricata against the sample PCAP file.
3. Examination of generated `fast.log` alerts.
4. Inspection of EVE JSON events.
5. Use of `jq` to filter and examine alert information.
